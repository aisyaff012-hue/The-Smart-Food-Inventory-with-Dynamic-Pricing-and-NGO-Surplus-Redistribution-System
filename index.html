Cara tunjuk kat penyelia

Ikut 5 langkah ni — semua peranan kongsi data yang sama, jadi setiap tindakan nampak merentas skrin.

  1. Log masuk sebagai Peniaga (aisyah@peniaga.com / 12345), buka Tambah Produk, masuk satu makanan dengan luput 3 jam. Tengok dia terus keluar di dashboard.
  2. Tekan laju masa ×600. Perhati meter kesegaran susut dan harga jatuh sendiri: Hijau → Kuning (−30%) → Merah (−70%).
  3. Tukar ke Pembeli. Barang diskaun sama muncul dalam katalog. Buat satu tempahan sampai dapat kod pickup.
  4. Balik ke Peniaga, tekan Hantar ke Derma NGO pada barang merah yang tak laku.
  5. Ke NGO → Request Donation, kemudian Sukarelawan untuk Accepted → Collected → Delivered.

Luput auto-masuk barisan derma

Meter kesegaran = 24 bar, satu bar satu jam. Ini elemen tanda aras app: harga tak ditetapkan manual, ia diseret turun oleh jam.

Nota prototaip

Semua data disimpan dalam ingatan pelayar sahaja — tiada backend, tiada bayaran sebenar. Set semula demo untuk mula balik dari awal. Fail ini boleh dibuka terus dari mana-mana pelayar, sesuai untuk demo luar talian.
